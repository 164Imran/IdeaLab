# IdeaLab

A collaborative web platform built for the AI student association of CY Tech (Paris-Cergy University). Members can submit project ideas, vote on proposals, and discuss directions for the association's work in artificial intelligence.

## Features

- Project proposal submission
- Community voting system
- Discussion threads per proposal
- Association member authentication

## Context

IdeaLab is an internal tool for the CY Tech AI association, used to organize the collective ideation process and prioritize projects for the semester.

## Stack

The project uses a standard web stack. Refer to the source files for dependency details.

## Usage

Clone the repository and follow the setup instructions in the source. Contact the association for access credentials.
